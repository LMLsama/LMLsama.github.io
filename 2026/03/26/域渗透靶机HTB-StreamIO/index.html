SMB 服务渗透–四个常用工具

smbmap

smbmap 是 SMB 共享枚举工具，-H 指定目标 IP，核心作用是快速探测目标主机开启的 SMB 共享、共享权限、可访问用户等基础信息。

**主要是探测/映射和扫描的作用 **

检测到一个 SMB 服务，但没有建立连接

smbclient

smbclient 是 SMB 客户端工具，-L 列出目标主机的 SMB 共享列表，-N 表示 “无密码认证”（匿名访问）。

主要是和 SMB 服务进行交互访问的

连接不允许

crackmapexec

crackmapexec（CME）是渗透测试核心工具，smb 模块用于批量探测 SMB 服务的系统信息、权限、漏洞等，无需凭证即可获取基础指纹信息。

综合性，这里只用到了探测。在动态目录的评估上不可或缺，靠山吃山，利用的是 window 内置协议，有一定免杀效果

除了最后一行都是初始化类输出（无需关注）：Creating home directory structure/Initializing SMB protocol database 等是 CME 首次运行的初始化操作，无实际攻击意义；

可以打开bloodhound 的详细操作帮助，只需要改变量即可

1. 生成安全字符串密码

  • 作用：将明文密码转换为 PowerShell 安全字符串（SecureString），避免明文直接暴露在脚本或内存中。
  • 参数解析
    • convertto-securestring：将普通字符串转换为安全字符串对象。
    • -AsPlainText：声明输入是明文，允许直接转换。
    • -force：强制执行转换（因为明文转安全字符串默认有安全警告，此参数绕过提示）。
  • 结果：变量 $pass 存储了加密后的密码对象，后续用于构造域凭据。

2. 构造域凭据对象

  • 作用：基于用户名和安全字符串密码，创建一个 PSCredential 对象，用于后续需要身份验证的 AD 操作。
  • 参数解析
    • system.management.automation.pscredential：.NET 类，用于封装用户名和密码。
    • 'streamio.htb\jdgodd'：目标域用户名，格式为 域\用户名（streamio.htb 是域名，jdgodd 是用户名）。
    • $pass：上一步生成的安全字符串密码。
  • 结果：变量 $cred 存储了完整的域凭据，可直接传递给需要 -Credential 参数的命令。

3. 查看域用户信息（前后两次）

  • 作用：查询本地 / 域用户 jdgodd 的详细信息，用于对比权限操作前后的变化。
  • 关键信息解读
    • **第一次查询：全局组只有 ***Domain Users（默认域用户组，权限较低）。
    • **第二次查询：全局组新增 ***CORE STAFF（说明权限操作已生效）。
  • 补充：net user 是传统 Windows 命令行工具，可快速查看用户状态、组归属、密码策略等。

4. 为用户添加目标对象的 ACL 权限

  • 作用：为域用户 streamio\jdgodd 授予对域组 Core Staff 的 ACL（访问控制列表）权限，通常是为了获取修改 / 加入该组的权限。
  • 参数解析
    • add-domainobjectacl：PowerShell 命令（通常来自 AD 模块或渗透工具如 PowerView），用于修改 AD 对象的访问控制列表。
    • -Credential $cred：使用之前构造的域凭据执行操作（规避当前会话权限不足的问题）。
    • -Targetidentity "Core Staff"：目标 AD 对象（这里是域组 Core Staff）。
    • -principalIdentity "streamio\jdgodd"：被授予权限的安全主体（即域用户 jdgodd）。
  • 本质：先让用户获得对 Core Staff 组的控制权限，为后续加入组做准备。

5. 将用户加入目标域组

  • 作用：将域用户 streamio\jdgodd 直接添加到高权限域组 Core Staff 中，完成权限提升。
  • 参数解析
    • add-domaingroupmember：AD 模块命令，用于向域组添加成员。
    • -credential $cred：使用构造的域凭据执行（若当前会话无权限，可通过已窃取的凭据提权操作）。
    • -identity "Core Staff"：目标域组。
    • -members "streamio\jdgodd"：要加入组的用户。
  • 结果：用户 jdgodd 获得 Core Staff 组的所有权限（若该组是高权限组，则实现横向移动 / 权限提升）。

工具&技术&思路总结

按功能分类的核心功能介绍：

一、信息收集与枚举

  • smbmap：枚举 Windows 主机 SMB 共享目录、权限，支持文件下载。
  • enum4linux：基于 SMB 的 Linux 枚举工具，可收集用户、共享、策略等信息。
  • ldapsearch：通过 LDAP 协议查询 Active Directory，用于域环境信息收集。
  • bloodhound.py：AD 域内数据采集器，收集用户、组、会话等关系数据。
  • powershell / powerview.ps1：PowerShell 环境下的 AD 域枚举脚本，查询用户、组、ACL 等。

二、漏洞探测与模糊测试

  • wfuzz：Web 应用模糊测试工具，支持目录爆破、参数注入、HTTP 头测试等。
  • gobuster / feroxbuster：目录/文件/子域名暴力破解工具，支持字典爆破与递归扫描。
  • hydra：网络登录密码爆破工具，支持 SSH、FTP、HTTP 等多种协议。
  • crackmapexec：内网渗透瑞士军刀，支持 SMB、WinRM、LDAP 等协议的批量认证、枚举与命令执行，配套数据库 cmedb 管理结果。

三、凭据获取与破解

  • hashcat：高性能密码哈希破解工具，支持 GPU 加速和多种哈希算法。
  • john (John the Ripper)：经典密码哈希破解工具，支持字典、规则和增量模式。
  • hash-identifier：识别哈希类型，为破解选择正确算法。
  • secretsdump.py (impacket)：从域控或本地转储 NTLM 哈希、Kerberos 票据。
  • firepwd.py：解密 Firefox 浏览器存储的密码。
  • laps (Local Administrator Password Solution)：管理并获取域中本地管理员密码的工具。

四、权限维持与横向移动

  • evil-winrm：基于 WinRM 协议的高交互 PowerShell 远程管理工具，常用于内网横向移动。
  • smbserver.py (impacket)：在攻击机创建 SMB 服务器，用于文件传输和 payload 投递。
  • bloodhound：图形化 AD 攻击路径分析工具，通过 Neo4j 数据库展示域内最短攻击路径。

五、数据与文本处理

  • sed / awk / tr / paste：Linux 命令行文本处理工具，用于日志分析、数据清洗、格式转换。
  • sqlcmd：Windows 下 SQL Server 命令行管理工具，可执行 SQL 查询和脚本。
  • sqlite / neo4j：数据库：SQLite 用于轻量数据存储；Neo4j 作为 BloodHound 的图数据库后端。

六、系统与网络配置

  • hosts：系统主机名解析文件，用于本地域名映射（如绕过 DNS、测试环境配置）。
  • curl：命令行 HTTP 客户端，支持多种协议，用于接口测试、文件下载、模拟请求。

建议组合使用：

  • 域渗透常用组合：bloodhound.py 采集 → neo4j + bloodhound 分析 → crackmapexec / evil-winrm 横向 → secretsdump.py 抓 hash → hashcat 破解。
  • Web 渗透常用组合：wfuzz / gobuster 发现路径 → curl 验证 → hydra 爆破登录。
